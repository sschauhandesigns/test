📎 How to add this to MathNest & Notion
1️⃣ Save this file as space-math-class3.html on your computer.
2️⃣ Go to tiiny.host or app.netlify.com/drop and drag & drop the file. You'll get a free public URL instantly.
3️⃣ Or deploy to GitHub Pages — push to a repo, enable Pages in settings, get a free URL.
4️⃣ In MathNest → Teacher Dashboard → Add Worksheet → paste the URL → assign to Class 3 → mark Visible.
5️⃣ In Notion → open your Class 3 page → type /embed → paste the same URL. Worksheet loads live inside Notion!
💡 Notion tip: Share settings → "Anyone with the link → Can view"
so students can open without a Notion account.
💡 GitHub tip: File must be named index.html or linked correctly in your repo.
